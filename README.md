#Flutter Hotel Booking Demo

A minimal Flutter demo app to showcase key UI features and functionality related to hotel bookings.

## Features

Browse a list of hotels (name, city, price, image)

View hotel details with smooth Hero animations

Book a hotel with a single tap and a confirmation Snackbar

View and manage your bookings list

Remove bookings with instant feedback

Live booking count shown on the home screen app bar

Total price displayed in the bookings list

## Built With

ListView.builder for dynamic hotel listing

Hero widget for smooth image transitions

SnackBar for user feedback

Navigator for screen transitions

StatefulWidget for dynamic state management

## Getting Started

# Prerequisites

Make sure Flutter is installed on your system:

```bash
flutter doctor
```

If not installed, follow the official installation guide:Flutter Install Guide

## Installation Procedure

Follow these steps to run the app locally on your Windows/macOS/Linux system:

###Clone the repository:

```bash
git clone https://github.com/yourusername/hotel_book_demo.git
```

###Navigate to the project directory:

```bash
cd hotel_book_demo
```
###Get all dependencies:

```bash
flutter pub get
```

###(Optional) Check for connected devices:

```bash
flutter devices
```

### Run the app:

```bash
flutter run
```

📱 You can run it on Android Emulator, iOS Simulator, or a physical device.
